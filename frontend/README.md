# Frontend — Resolva

Interface inicial da plataforma **Resolva**, uma aplicação de gestão de serviços técnicos.

## Executar localmente

Abra `index.html` num navegador ou sirva a pasta com qualquer servidor estático:

```bash
cd frontend
python3 -m http.server 8080
```

Depois aceda a `http://localhost:8080`.

A interface implementa o primeiro ecrã definido no briefing (visão geral), com navegação para pedidos, orçamentos e mensagens, criação de pedido, filtragem de estados e layout responsivo. A autenticação, API, persistência de dados e pagamentos ficam preparadas para a próxima fase do MVP.
